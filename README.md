# Titanic Survival Analysis

## About the Project
This project analyzes the Titanic passenger dataset using Python. It explores passenger details and survival patterns.

## Libraries Used
- Pandas
- Matplotlib
- Seaborn

## Analysis
- Loaded and explored the dataset.
- Checked missing values.
- Filled missing Age and Embarked values.
- Calculated the survival rate.
- Compared survival by gender and passenger class.
- Created graphs to understand the results.

## Key Findings
- Total passengers in the dataset: 891
- Passengers who survived: 342
- Passengers who did not survive: 549
- Overall survival rate: 38.38%

Female passengers had a higher survival rate than male passengers in this dataset. First-class passengers also had a higher survival rate than third-class passengers.

## How to Run
Run `main.py` using Python after installing Pandas, Matplotlib, and Seaborn.
